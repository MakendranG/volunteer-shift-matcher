## Description

```
A Good Neighbor agent for the Agents for Humans hackathon. Food banks and small nonprofits lose volunteer shifts because a stretched-thin coordinator has to match everyone's availability and skills to open shifts by hand. This agent does it in seconds — building an auditable match plan, drafting warm confirmations for each volunteer, and writing "help needed" broadcasts for the shifts it can't fill — so communities stay staffed and neighbors get served. Built with the Strands Agents SDK + Amazon Bedrock.
```
